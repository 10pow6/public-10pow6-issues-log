# 10pow6 — Public Issue Tracker

Welcome! This is the **public bug & feedback tracker** for **10pow6 core**: the [10pow6.com](https://10pow6.com) landing site and [**10pow6 Accounts**](https://accounts.10pow6.com), the one account that signs you in to every 10pow6 product. Accounts is also where you manage security (MFA, recovery codes, passkeys), your **TP6 wallet**, connected apps and spend limits, API keys, and recurring charges.

This repository contains **no source code**. It exists so users can report bugs, request features, and track what we're working on — all in the open.

---

## 🐛 Found a bug? Have an idea?

[**→ Open a new issue**](https://github.com/10pow6/public-10pow6-issues-log/issues/new/choose)

Pick the right template and fill in as much as you can:

| Template | Use it when… |
|----------|--------------|
| 🐛 **Bug Report** | Sign‑up, sign‑in, MFA, your wallet, a TP6 purchase, connected apps, API keys, or the 10pow6.com site isn't working right. |
| ✨ **Feature Request** | You have an idea for your account, the wallet, the site, or a quality‑of‑life improvement. |

Before opening one, please [**search existing issues**](https://github.com/10pow6/public-10pow6-issues-log/issues?q=is%3Aissue) — if your bug or idea already exists, add a 👍 or a comment instead of opening a duplicate. It helps us prioritize.

## 🔒 Security issues

**Do not** open a public issue for security vulnerabilities. [**Report it privately →**](https://github.com/10pow6/public-10pow6-issues-log/security/advisories/new) (see [**SECURITY.md**](SECURITY.md) for what to include and what's out of scope).

> ⚠️ Reports involving **sign‑in, MFA, or recovery**, **TP6 balances or purchases**, connected‑app **spend limits**, **API keys**, or anything that could expose another user's account or wallet are **security‑sensitive**. Report those privately, not here.

## 💬 Want to chat instead?

Join the community on **Discord** (linked from [10pow6.com](https://10pow6.com)) for live discussion, help, and announcements. GitHub issues are best for things we need to track and fix; Discord is best for questions and conversation.

## How we handle issues

- We triage new issues and apply labels (e.g. `bug`, `enhancement`, `needs-info`, `confirmed`, `wontfix`).
- Bug reports are labeled `env: beta` or `env: prod` from the **Environment** you pick, so tell us where you saw it.
- If we need more detail we'll add `needs-info` and comment — please reply, or we may close the issue after a while.
- Fixed issues are closed with a note. Shipped features are closed when they go live.
- This is the canonical place to see **what's reported and what's planned** for 10pow6 core.

## Tips for a great report

1. **One issue per report.** Separate bugs into separate issues.
2. **Be specific.** "The Buy button on a TP6 package does nothing" beats "the wallet is broken."
3. **Include steps** to reproduce, what you expected, and what actually happened.
4. **Add screenshots** when the bug is visual. Crop out your email address, balance, and anything private first.
5. **Tell us your setup**: browser, device, and the page you were on.
6. **Never post secrets.** No passwords, recovery codes, authenticator codes, API keys, or payment details, ever. We will never ask for them.
